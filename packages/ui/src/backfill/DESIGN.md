The backfill form is a shared `Modal` with shared buttons, Wplace theme tokens, and system font. A compact artwork preview identifies the selected template. One full-width native snapshot selector carries the only import choice. Coverage and running results sit below it; footer actions stay grouped at the bottom. The modal scrolls within the viewport and wraps actions at phone width. Escape closes it; a press on the backdrop does not, so a long import is not dismissed by accident.
