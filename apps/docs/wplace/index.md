Unofficial community docs for building apps, mods, userscripts and plugins for [Wplace](https://wplace.live). Wplace publishes no API docs. Everything here comes from reading the public wplace.live web client and calling its public endpoints.

The Wplace team does not write or review these docs. Endpoints change without notice, so check the date on each page.

## Ground rules

These docs describe how Wplace works. They do not explain how to cheat, bot, or get around Wplace's limits, anti-cheat or bans, and contributions that do are not accepted.

Wplace's rules ban painting with automation tools, multiple accounts and other "technical means to interact with pixels in an unauthorised manner". A mod that reads the map, draws overlays, or organises a group stays clear of that. A mod that paints for the player does not.
