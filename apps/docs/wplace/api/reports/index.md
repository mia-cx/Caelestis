Reports and ban appeals. Some carry a Pawtect token. A mod must not file reports on the player's behalf.

- [[Report-player|Report a player]]: Report a player for griefing or another rule break, with the map view attached.
- [[Report-player-name|Report a player's name]]: Report a player's display name as offensive.
- [[Report-player-profile|Report a player's profile]]: Report a player's name or picture, with the content the reporter saw.
- [[Report-alliance|Report an alliance]]: Report an alliance's headquarters or assets, with the area and view attached.
- [[Report-alliance-name|Report an alliance name]]: Report an alliance's name as offensive.
- [[Submit-ban-appeal|Appeal a ban]]: Send a ban appeal message, optionally tied to a support ticket.
