How the `j` session cookie is set and cleared.

- [[Sign-in|Sign in]]: Start signing in with Google, Apple or Twitch, which sets the `j` cookie.
- [[Create-mobile-session|Finish an iOS app sign-in]]: The form the iOS app posts after a sign-in redirect, to exchange the one-time code for a session.
- [[Sign-out|Sign out]]: End the signed-in player's current session.
- [[Link-discord|Link Discord]]: Start linking a Discord account to the signed-in player.
- [[Unlink-discord|Unlink Discord]]: Remove the Discord account linked to the signed-in player.
