---
title: Get my email
description: Get the email address on the signed-in player's account.
tags:
  - source/bundle
  - pawtect/flag
operation:
  protocol: rest
  method: GET
  path: /me/email
  auth:
    scheme: session cookie
    description: The `j` cookie of a signed-in player.
  parameters:
    - name: j
      in: cookie
      required: true
      type: string
      example: <session-cookie>
      description: Wplace session cookie, set when the player signs in.
  responses:
    "200":
      description: The email.
      example:
        email: player@example.com
    "401":
      description: No session, or an expired one.
      schema:
        $ref: Error
---

**Pawtect:** No token. The client reads this response through its API client, so patching its `json` or `text` sets "Tampered response" ([[Anti-cheat]]). Any absolute URL fetched through the page's `window.fetch` goes into the next token's URL log.

In the client bundle, never called by the player UI. Checked on 26 November 2026. **Unverified:** read from the client code, since the guide makes no signed-in requests.
