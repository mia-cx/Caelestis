Public alliance data, readable without an account, plus the requests a player sends to join one. The player's own alliance is under [My alliance](../my-alliance/).

- [[List-alliances|List alliances]]: Browse and search the public alliance gallery, 20 alliances per page.
- [[Get-alliance|Get an alliance]]: Get an alliance's public profile by id: description, members, awards and headquarters.
- [[List-alliance-members|List an alliance's members]]: List an alliance's public members and roles, 50 per page.
- [[List-alliance-awards|List an alliance's awards]]: List an alliance's awards with tier, progress and thresholds.
- [[Get-alliance-headquarters|Get an alliance's headquarters]]: Get where an alliance's headquarters sits on the map, its size and canvas version.
- [[Get-alliance-headquarters-manifest|Get a headquarters tile manifest]]: List the tiles of an alliance's headquarters canvas with their versions.
- [[Get-alliance-headquarters-snapshot|Get a headquarters snapshot]]: Download the changed tiles of a headquarters area in one binary response.
- [[Get-alliance-headquarters-image|Get a headquarters image]]: Download an alliance's whole headquarters canvas as one image.
- [[Get-alliance-picture|Get an alliance picture]]: Download an alliance's profile picture by id and version.
- [[Get-alliance-banner|Get an alliance banner]]: Download an alliance's profile banner by id and version.
- [[List-headquarters-pins|List headquarters pins]]: List the alliance headquarters shown on the map inside a latitude and longitude box.
- [[Get-alliance-viewer|Get my standing with an alliance]]: Check whether the signed-in player is a member of an alliance, or has asked to join.
- [[Join-open-alliance|Join an open alliance]]: Join an alliance whose join policy lets anyone in.
- [[Request-to-join-alliance|Ask to join an alliance]]: Send a join request to an alliance that reviews new members.
