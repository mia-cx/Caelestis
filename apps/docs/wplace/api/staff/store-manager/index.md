---
title: "Staff: store manager"
description: Staff-only routes for cosmetics, badges, frames and store images.
---

These routes serve Wplace's staff dashboard, which ships inside the public client. They are listed so mod authors can recognise them in the bundle. Players get `401` or `403`. Their notes describe what each route is for, and nothing more.

- [[Staff-List-cosmetics|List cosmetics (staff)]]: Staff-only route that lists name cosmetics in the store manager.
- [[Staff-Edit-a-cosmetic|Edit a cosmetic (staff)]]: Staff-only route that edits a name cosmetic.
- [[Staff-Delete-a-cosmetic|Delete a cosmetic (staff)]]: Staff-only route that deletes a name cosmetic.
- [[Staff-List-badges|List badges (staff)]]: Staff-only route that lists badges in the store manager.
- [[Staff-Create-a-badge|Create a badge (staff)]]: Staff-only route that creates a badge.
- [[Staff-Edit-a-badge|Edit a badge (staff)]]: Staff-only route that edits a badge.
- [[Staff-Delete-a-badge|Delete a badge (staff)]]: Staff-only route that deletes a badge.
- [[Staff-Create-a-frame|Create a frame (staff)]]: Staff-only route that creates a profile frame.
- [[Staff-Add-a-name-font|Add a name font (staff)]]: Staff-only route that adds a font for name cosmetics.
- [[Staff-Add-a-name-style|Add a name style (staff)]]: Staff-only route that adds a style for name cosmetics.
- [[Staff-List-store-images|List store images (staff)]]: Staff-only route that lists images uploaded in the store manager.
- [[Staff-Upload-a-store-image|Upload a store image (staff)]]: Staff-only route that uploads an image in the store manager.
- [[Staff-Delete-a-store-image|Delete a store image (staff)]]: Staff-only route that deletes an image from the store manager.
