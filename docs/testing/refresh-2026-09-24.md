## Selected contracts

- `test/wplace-import-contract.test.ts` uses the reported United Pixels export and synthetic recipes.
  Real decoding, resizing, palette indexing, alpha boundaries, and IndexedDB persistence run together.
  Native module discovery and the native worker remain external; this suite does not claim to reproduce Wplace's dithering implementation.
- `tests/claim-lifecycle.test.ts` verifies cross-token deletion, refused edits/withdrawals, and deletion tombstones through HTTP and SQLite.
  `test/claim-routing-contract.test.ts` verifies persisted retry/deletion intent and unchanged snapshot delivery.
  Retained claim-document and presence-claims tests cover actual raster grouping, subtraction, surface separation, and budgets.
- `tests/support/scheduler-contract.ts` runs identical fencing behavior on SQLite, PostgreSQL, and MariaDB.
  A separate SQLite case upgrades a populated v1 scheduler and verifies failed-handler retry.
- `tests/upload-recovery.test.ts` replaces the inherited SQLite-as-D1 fake and sleep-based upload tests.
  Actual SQLite stores observations while the external object store fails and recovers.
  `tests/ingest-concurrency.test.ts` holds real storage operations to verify shared PUTs before upload/commit,
  separate reporter observations, started-offer settlement, and queued-offer cancellation on failure.
  `tests/derived-artifact-contract.test.ts` replaces private call-count assertions with queue bounds, acknowledgment, persisted bytes, and rebuild behavior.
- Both clients' `api-boundary.test.ts` suites now exercise public branding against backend routes.
  Existing server-route tests retain malformed input, authorization, sparse edits, asset replacement races, and failed storage coverage.
  The D1 contract also verifies sparse branding persistence.
- `data-contracts.test.ts` now measures observed matching-pixel changes instead of deleted activity-based pace functions.
  `raster-contracts.test.ts` checks GIF frame delays for irregular timestamps. Retained timelapse and chart DOM tests cover bounded controls, pause/speed/seek, keyboard interaction, and graph synchronization.
- Retained Shift-paint tests now cover native swatch changes during interaction, alongside crossed pixels, unknown tiles, cancellation, and alliance bypass.
  Charge forecast, map readiness, layout invalidation, branding sanitation, and server-dialog interaction cases remain because they cover distinct public outcomes.
- Browser contracts recover a tile loaded before hook installation, decode it in Chromium, and verify production canvas capture and mismatch-worker lifecycle.
  The runner owns its tab and retains focus emulation until it closes that tab.
- Retained capacity, classification equivalence, bounded shared classification, fold-throttling, and timing-report cases cover their exported contracts.
  `pnpm test:performance` runs the warmed classification benchmark separately. CI runs it on Node and Bun without coverage instrumentation.
- Workflow tests preserve approved Dependabot head validation and both nested release-secret boundaries.
  Updated workflow commands execute the replacement fixture, telemetry, social, database, D1, and runtime suites.
- Legacy IndexedDB fixtures exercise Blob palette migration, corrupt-row continuation, blocked-open recovery, and abandoned connection cleanup.
  Concurrent HTTP uploads pause at real SQL alarm evaluation and release loss/recovery in both orders, preserving closed alarms and cleared deadlines.
  The permission matrix checks admitted scopes as well as refusals. Browser commands have bounded CDP requests and child-process cleanup.

Default backend/userscript discovery includes both replacement directories and newer `src/**/*.test.ts` files.

for already-merged styling changes; its browser check uses controlled tile responses and never writes to Wplace.

## Runtime prerequisites

Bun uses the system SQLite on macOS and its bundled build on Linux. Apple's SQLite 3.54.0 on the
validation machine rejects migration 0002's qualified CHECK constraints during table rename.
The standalone SQL reproduction fails without Vitest. Homebrew SQLite 3.53.3 applies the same
immutable migrations successfully. See [Bun's SQLite documentation](https://bun.sh/docs/runtime/sqlite).

Local runtime checks can explicitly select that library:

```sh
CAELESTIS_TEST_SQLITE_LIBRARY=/opt/homebrew/opt/sqlite/lib/libsqlite3.dylib pnpm test:runtime
```

This affects the test process only. Linux CI leaves the option unset and tests the shipped runtime.
